# Aastha's Princess Day Surprise 👑

A cute, mobile-friendly Princess Day webpage with a personal wish, twinkling stars, confetti, and a playable mini-game. It uses only HTML, CSS, and JavaScript — no libraries, sign-in, or paid services.

## Publish free with GitHub Pages
1. Download and unzip `aastha_princess_day_github_pages.zip`.
2. Create a new repository on GitHub (for example, `aastha-princess-day`).
3. Upload `index.html` to the repository's root and commit the changes.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main**, folder **/(root)**, then press **Save**.
7. Wait a minute or two. GitHub will show the website URL, usually `https://YOUR-USERNAME.github.io/aastha-princess-day/`.
8. Open the URL on your phone to test it, then send it to Aastha.

## Customize
Open `index.html` in any text editor. Search for the wish text, the sign-off, or `Aastha` to personalize it. No external image or music files are required.
